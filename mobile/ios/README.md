# VeriPay iOS SDK

Implements PLAN §15, §16 for iOS: Secure Enclave-backed ECDSA P-256 key pairs,
Apple App Attest attestation, single-use 128-bit challenge nonces (90s expiry),
and secure in-app dCVV display requiring biometric confirmation.
