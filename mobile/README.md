# VeriPay Mobile SDKs

Device integrity, cryptographic identity, and dCVV display (PLAN §15, §16).

## ios/
Swift package: iOS Secure Enclave key generation, Apple App Attest,
ECDSA over NIST P-256, biometric step-up, secure dCVV display.

## android/
Kotlin module: Android Keystore, Google Play Integrity, biometric
step-up, secure dCVV display.
